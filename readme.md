## 📁 Estructura del proyecto

```
FABIAN-BELTRAN/
├── index.html              # Página principal
├── css/
│   ├── main.css            # Punto de entrada — importa todos los módulos
│   ├── base.css            # Variables, reset, tipografía, utilidades globales
│   ├── nav.css             # Navbar responsive con Bootstrap
│   ├── hero.css            # Sección hero, bio, stack pills, CTAs
│   ├── skills.css          # Cards de habilidades técnicas
│   ├── timeline.css        # Sección trayectoria / educación
│   ├── projects.css        # Cards de proyectos + filtros
│   ├── contact.css         # Sección contacto + offcanvas formulario
│   ├── footer.css          # Footer
│   ├── widget.css          # Widget flotante de contacto
│   └── aos.css             # Librería AOS (animaciones scroll)
├── js/
│   ├── script.js           # Lógica principal
│   ├── aos.js              # Librería AOS local
│   └── typed.umd.js        # Librería Typed.js local
├── assets/
│   ├── icons/              # SVGs de tecnologías (Devicons)
│   └── cv-fabian-beltran.pdf
├── fonts/
│   ├── space-grotesk-v22-latin-*.woff2
│   └── ibm-plex-mono-v20-latin-*.woff2
├── favicon/
│   └── favicon_base.png
├── .gitignore
├── package.json
└── README.md
```

## 🛠️ Stack técnico

| Categoría | Tecnología |
|-----------|-----------|
| Estructura | HTML5 semántico |
| Estilos | CSS3 modular |
| Framework CSS | Bootstrap 5.3 |
| Íconos | Bootstrap Icons 1.13 |
| Fuentes | Space Grotesk, IBM Plex Mono |
| Animaciones scroll | AOS (Animate On Scroll) |
| Efecto typing | Typed.js |
| Formulario | Formspree API |
| Control de versiones | Git + GitHub |

## 📌 Secciones

| Sección | Descripción |
|---------|-------------|
| **Hero** | Presentación, bio, stack pills, CTAs y links sociales |
| **Habilidades** | Frontend, Backend y Herramientas en cards interactivas |
| **Trayectoria** | Timeline de formación académica y experiencia |
| **Proyectos** | Galería con filtro Backend / Frontend / Todos |
| **Footer** | Links de navegación, redes sociales y estado de disponibilidad |
| **Widget flotante** | Acceso rápido a contacto y formulario offcanvas desde cualquier sección |

## ✨ Características

- ✅ Diseño dark mode con paleta **Carbón + Naranja**
- ✅ Totalmente responsive — mobile, tablet y desktop
- ✅ Navbar con collapse nativo de Bootstrap
- ✅ Filtro de proyectos por categoría (Backend / Frontend)
- ✅ Widget flotante de contacto fijo en toda la página
- ✅ Formulario offcanvas con integración a **Formspree**
- ✅ Notificación de éxito/error al enviar el formulario
- ✅ CSS modular organizado por secciones
- ✅ Fuentes locales (sin dependencia de Google Fonts)
- ✅ Animaciones con AOS y Typed.js (instalación local)

## 📦 Instalación local

```bash
# Clonar el repositorio
git clone https://github.com/fabian1031/fabian-beltran-portafolio.git

# Entrar al proyecto
cd portafolio

# Instalar dependencias (AOS, Typed.js)
npm install

# Abrir index.html en el navegador
# O usar Live Server en VS Code
```
